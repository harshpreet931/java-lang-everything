# java.lang.everything

java, all the way down. by [Harshpreet Singh](https://harshpreet.com) ([harshpreet.com](https://harshpreet.com)).

an open-source guide that draws java instead of describing it. 18 parts, 192 chapters, from `int x = 5` to the garbage collector. every figure is interactive, every snippet runs, every number was measured. free, forever.

## what's different

- **figures, not walls of text.** step through code and watch the stack and heap change. put keys into a HashMap and watch them land. race two threads on `count++`. slide a recursion depth until the stack overflows.
- **code that runs.** java snippets compile and run right in your browser (javac compiled to wasm, no server). every snippet is also run on a real JDK 25 in CI.
- **traces from real runs.** the stack/heap step-throughs can be generated by a tiny JDI debugger (`tools/tracer`) that actually runs the program.
- **numbers that are measured.** stack depths, class load counts, JIT tiers, GC logs: captured from jdk 25, with the machine named.
- **one voice.** lowercase, casual, dense. like a friend explaining the JVM with a whiteboard.

## run it

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # static site in out/, with full-text search
```

needs node 22.12+ and pnpm 10. the java checks need a JDK 25+.

## how it's built

```
content/<part>/<chapter>.mdx      the chapters
src/content/curriculum.ts         the book's order, titles and blurbs
src/components/viz/               generic figures (MemoryStepper, ArrayViz, Bits, Tree, Flow...)
src/components/figures/<part>/    bespoke figures for one part
src/mdx/                          the mdx pipeline (shiki themes, code-block meta, toc)
src/lib/java/                     run java in the browser (teavm-javac, wasm)
tools/tracer/                     JDI tracer: real program → step-through json
scripts/                          check.mjs (compile + voice lint), java-check.mjs (run snippets)
```

next.js 16 (static export), mdx, tailwind 4, shiki. set in Crimson Pro, Cormorant Garamond and JetBrains Mono.
